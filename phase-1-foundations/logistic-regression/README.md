# Logistic Regression

This section studies **Logistic Regression** through paper-inspired applications in credit risk, macroeconomics, and financial markets.

The exercises progress from basic binary classification to threshold tuning, cost-sensitive classification, rare-event prediction, and financial-market direction forecasting.

## Problems

| Problem | Application |
|---|---|
| Problem 5 | Credit Risk Classification Using German Credit Data |
| Problem 5A | Threshold Tuning and Cost-Sensitive Credit Risk |
| Problem 6 | Predicting U.S. Recession Probability Using the Yield Curve |
| Problem 6A | Threshold Tuning for Recession Prediction |
| Problem 7 | Forecasting Monthly Stock-Market Direction |

## Concepts Covered

- Logistic Regression
- Binary classification
- Predicted probabilities
- Classification thresholds
- Confusion matrices
- Precision, recall and F1-score
- ROC curves and ROC-AUC
- Threshold tuning
- Cost-sensitive classification
- Rare-event prediction
- Benchmark comparison
