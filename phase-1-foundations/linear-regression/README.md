# Linear Regression

This section studies **Linear Regression** through paper-inspired applications in financial engineering and climate economics.

The exercises progress from simple linear regression to multiple regression and panel-data methods with fixed effects and interaction terms.

## Problems

| Problem | Application |
|---|---|
| Problem 1 | CAPM Beta Estimation for the U.S. Energy Industry |
| Problem 2 | CAPM vs. Fama-French 3-Factor Model |
| Problem 3 | Temperature Shocks and Economic Growth |

## Concepts Covered

- Simple linear regression
- Alpha and beta estimation
- Residual analysis
- R² and adjusted R²
- Multiple linear regression
- Factor models
- Panel data
- Country and year fixed effects
- Interaction terms
- Clustered standard errors
