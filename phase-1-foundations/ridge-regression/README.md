# Ridge Regression

This section studies **Ridge Regression** through empirical applications in financial engineering, macroeconomics, and climate economics.

Ridge Regression introduces L2 regularisation, which shrinks regression coefficients to reduce overfitting and improve model stability, particularly when predictors are highly correlated.
