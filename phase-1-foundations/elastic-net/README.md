# Elastic Net Regression

This section studies **Elastic Net Regression** through empirical applications in financial engineering, macroeconomic forecasting, and climate economics.

Elastic Net combines L1 (LASSO) and L2 (Ridge) regularisation, allowing both coefficient shrinkage and automatic feature selection. It is particularly useful when predictors are highly correlated and a balance between sparsity and model stability is desired.
