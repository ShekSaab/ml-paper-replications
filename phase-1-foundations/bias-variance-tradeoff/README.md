# Bias–Variance Trade-off

This section studies the **Bias–Variance Trade-off** through an empirical exercise examining how increasing model complexity affects in-sample fit and out-of-sample performance.

Polynomial regression models of increasing degrees are used to explore the relationship between model complexity and generalisation.

## Problems

| Problem | Application |
|---|---|
| Problem 4 | Predicting Energy Industry Returns with Increasing Model Complexity |

## Concepts Covered

- Bias–variance trade-off
- Model complexity
- Polynomial regression
- Training and test sets
- Training and test error
- RMSE
- Underfitting
- Overfitting
- Out-of-sample generalisation
- Numerical instability at high polynomial degrees
