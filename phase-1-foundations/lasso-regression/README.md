# LASSO Regression

This section studies **LASSO (Least Absolute Shrinkage and Selection Operator) Regression** through empirical applications in financial forecasting and climate economics.

LASSO introduces L1 regularisation, which shrinks regression coefficients and can set some coefficients exactly to zero, enabling automatic feature selection and producing more parsimonious models.
